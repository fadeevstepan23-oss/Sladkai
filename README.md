# 1618 Avenue — демо-лендинг салона красоты

Лёгкий статический лендинг с онлайн-записью по часовым ячейкам.
Открывается двойным кликом по `index.html` — сборка и сервер не нужны.

```
index.html              вся разметка страницы
assets/css/style.css    стили и палитра
assets/js/app.js        каталог, календарь, слоты, форма записи
assets/img/*.svg        временные иллюстрации-плейсхолдеры
```

## Что внутри

* **Первый экран** — заголовок, преимущества, живые облака, сахарная вата и блёстки.
* **Каталог услуг** — карточки с ценой и длительностью, фильтр по категориям.
  Кнопка «Записаться» в карточке предвыбирает услугу в форме.
* **Онлайн-запись** — календарь на месяц (листается вперёд), в каждой дате видно,
  сколько часов свободно. По клику на дату открывается сетка часовых ячеек
  с 10:00 до 21:00: «свободно» / «занято» / «вы записаны».
* **Форма записи** — услуга, мастер, имя, телефон, комментарий; после подтверждения
  ячейка закрашивается, запись появляется в блоке «Мои записи», её можно отменить.
* **Мастера, галерея, отзывы, контакты** — блоки под реальный контент салона.

Демо-занятость часов генерируется детерминированно по дате, поэтому картинка
не «прыгает» при перезагрузке. Свои записи хранятся в `localStorage` браузера.

## Что нужно заменить на боевые данные

1. **Фото.** Сейчас в `assets/img/` лежат сгенерированные SVG-заглушки.
   Положите рядом реальные снимки под теми же именами (`manicure.jpg` и т.д.)
   и поправьте пути в `index.html` и в массивах `SERVICES` / `MASTERS` (`assets/js/app.js`).
   Сайт салона на момент сборки был недоступен из среды разработки, поэтому
   оригинальные фотографии не перенесены.
2. **Услуги и цены** — массив `SERVICES` в начале `assets/js/app.js`.
3. **Мастера** — массив `MASTERS` там же.
4. **Часы работы** — объект `WORK` (`open` / `close`).
5. **Контакты** — блок `#contacts` и подвал в `index.html`, плюс телефон в шапке.
6. **Карта** — блок `.map-card` заменить на iframe Яндекс.Карт.

## Подключение Telegram-бота (следующий шаг)

В `assets/js/app.js` внизу есть точка интеграции:

```js
var TELEGRAM = {
  enabled: false,
  endpoint: ''   // адрес своего backend-обработчика
};
```

Токен бота нельзя держать в коде страницы — его видно любому посетителю.
Схема такая: страница отправляет заявку на свой маленький backend,
а он уже дёргает Telegram Bot API и пишет менеджеру в чат.

Минимальный обработчик (Node.js / любая serverless-функция):

```js
export default async function handler(req, res) {
  const { text } = req.body;                    // готовый текст заявки формирует лендинг
  await fetch(`https://api.telegram.org/bot${process.env.BOT_TOKEN}/sendMessage`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ chat_id: process.env.MANAGER_CHAT_ID, text })
  });
  res.json({ ok: true });
}
```

После этого в `TELEGRAM` достаточно поставить `enabled: true` и указать `endpoint`.
Тогда же имеет смысл перенести занятость часов из браузера в общую базу,
чтобы календарь был одинаковым для всех гостей.

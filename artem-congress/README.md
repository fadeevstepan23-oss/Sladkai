# Презентация для конгресса — «Субаренда коммерческой недвижимости»

Черновой вариант доклада Артёма Панасенко: 40 слайдов, 7 блоков.
Структура по слайдам и вопросы к Артёму — в [STRUKTURA.md](STRUKTURA.md).

```
index.html                 все слайды (рабочий файл)
assets/css/deck.css        дизайн-система: цвета, шрифты, сетка, анимации, печать
assets/css/slides.css      раскладки отдельных слайдов
assets/js/deck.js          навигация, масштаб, анимации входа, обзор, заметки, график
assets/img/                фото из прошлой презентации (уже обработаны: ч/б и приглушённый цвет)
assets/fonts/              Onest и JetBrains Mono — локально, интернет на площадке не нужен
dist/presentation.html     всё в одном файле — переслать и открыть двойным кликом
dist/presentation.pdf      PDF 1920×1080 для отправки в мессенджер
tools/build.py             пересобирает dist/presentation.html
tools/export-pdf.js        пересобирает PDF (нужен Playwright)
```

## Управление

| Клавиша | Действие |
|---|---|
| → / пробел / клик справа | следующий слайд |
| ← / клик слева | предыдущий слайд |
| O или Esc | обзор всех слайдов |
| N | заметки к слайду: откуда цифры и что уточнить |
| D | скрыть пометки черновика (бордовый пунктир) |
| F | полный экран |

Номер слайда хранится в адресе: `index.html#26` откроет 26-й слайд.

## Визуальный язык

Слайд оформлен как лист архитектурного чертежа. Это прямо связано с темой
доклада: субаренда — это деление площади.

- **Чертёжные элементы.** Тонкие линии, метки по углам листа, штамп
  «Лист 07 / 40», размерные линии, планировки с дверями и окнами,
  штриховка вместо пустых фото.
- **Сквозной мотив — деление.** На титуле помещение 120 м² делится на блоки.
  На обложках разделов прямоугольник плана каждый раз разделён на большее число
  блоков: от одного до шести.
- **Палитра.** Бумага `#F2EFE9`, графит `#171615`. Бордо PREMIER `#8A2A3A` —
  только точечно. Бронза `#A9772F` — только вторая серия на графиках.
  Пара бордо и бронзы проверена на различимость при нарушениях цветового зрения.
- **Шрифты.** Onest — тонкие крупные заголовки, JetBrains Mono — подписи в стиле
  чертежа.
- **Анимация.** Сдержанная. Текст проявляется из лёгкого расфокуса снизу.
  Контуры планов прорисовываются линией, фото открываются шторкой, цифры набегают.
  Слайды сменяются наплывом.

## Пересборка после правок

```bash
python3 artem-congress/tools/build.py          # dist/presentation.html
node artem-congress/tools/export-pdf.js        # dist/presentation.pdf
node artem-congress/tools/export-pdf.js --clean  # PDF без пометок черновика
```

## Куда вставлять фото объектов

На слайдах 28–31 вместо фото стоят заштрихованные блоки
`<div class="slot case-slot …">`. Чтобы поставить фото, положите файл
в `assets/img/` и замените блок на:

```html
<figure class="ph mute r reveal"><img src="assets/img/vosstaniya.jpg" alt="…"></figure>
```

Таким же блоком (`div.slot`) отмечен QR-код для записи на ужин (слайд 38).

## PowerPoint-версия финала

В `pptx/` лежит итоговая 48-слайдовая версия, переведённая из PDF:

- `Субаренда — Панасенко (редактируемая).pptx` — фон слайда (фото, линии, планы)
  картинкой, весь текст — редактируемые блоки со шрифтами Onest и JetBrains Mono.
  Перед открытием установите шрифты из `Шрифты для презентации.zip`.
- `Субаренда — Панасенко (точная копия).pptx` — каждый слайд одной картинкой,
  выглядит одинаково на любом компьютере. Подходит для показа на площадке.

Пересборка из PDF: `python3 artem-congress/tools/pdf2pptx.py final.pdf out.pptx <папка со статичными TTF> <рабочая папка> editable|image`
(нужны `pymupdf`, `fonttools`, `python-pptx`).

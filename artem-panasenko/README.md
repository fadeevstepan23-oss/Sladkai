# Артём Панасенко · Проявленность — презентация

Веб-презентация на 6 слайдов для ПК: обложка, цель, ядро личности, форматы
(со вшитыми роликами), монетизация, гипотезы по воронкам.

```
index.html   разметка, стили и скрипт
img/         фото и обложки роликов
video/       4 ролика, сжатые для веба (540×960)
fonts/       Cormorant Garamond и Montserrat — работают без интернета
```

## Как показывать

* Стрелки ← →, пробел, колесо мыши, свайп или кнопки внизу справа.
* Кнопка ⛶ или клавиша F — полноэкранный режим.
* Ролик открывается кликом по карточке на 4-м слайде, Esc — закрыть.
* Ссылка на конкретный слайд: `…/#3`.

Сцена нарисована в 1600×900 и масштабируется под любой экран без перекосов.

## Деплой на Netlify

Перетащить папку `artem-panasenko` целиком в Deploys сайта
(или подключить репозиторий и указать publish directory `artem-panasenko`).

## Где менять цифры

Цель и воронка — слайд 2 (`data-name="Цель"` в `index.html`): охват
300 000, доход 1 млн ₽, 10 млн ₽ инвестиций, конверсии 0,3% / 10% / ~11%.
Это расчётные ориентиры — сверить с Артёмом.
